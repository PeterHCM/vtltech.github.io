Eaton Power Distribution

Rơ-le lập trình Eaton easyE4

Rơ-le lập trình easyE4 cho điều khiển tự động quy mô nhỏ: Ethernet tích hợp, mở rộng I/O, lập trình bằng easySoft với nhiều ngôn ngữ.

  • Module cơ sở có/không màn hình, nhiều cấp điện áp
  • Ethernet tích hợp, kết nối Modbus TCP, web server
  • Mở rộng I/O số, tương tự, nhiệt độ
  • Lập trình easySoft: LD, FBD, ST, EDP

Tổng quan

easyE4 là thế hệ rơ-le lập trình mới của Eaton, thay thế PLC nhỏ trong các ứng dụng điều khiển chiếu sáng, bơm – quạt, cửa, băng tải và tủ điều khiển máy. Ethernet tích hợp cho phép giám sát và cập nhật chương trình từ xa.
